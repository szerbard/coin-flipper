# Coin Flipper

Flip a virtual coin with 3D animation and track heads/tails statistics.

## How to Use

**Step 1:** Open `index.html` in your browser.

**Step 2:** An onboarding tutorial appears on first visit. Click **Start Flipping** (or Skip).

**Step 3:** Click the **Flip!** button. The coin spins with a 3D animation.

**Step 4:** The result (Heads or Tails) appears below the coin.

**Step 5:** Keep flipping! The stats update with each flip showing count and percentage.

**Step 6:** The colored bar shows the Heads vs Tails split visually.

**Step 7:** Scroll down to see the flip history.

## Features
- 3D coin flip animation
- Heads/Tails count and percentage
- Visual percentage bar
- Flip history (last 20)
- Responsive design

## Tech
HTML + CSS + JavaScript | CSS 3D transforms
